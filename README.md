# AI Image Metadata Extractor

A simple, privacy-friendly tool to help users extract generation details from AI-generated images. By uploading an image, you can instantly recover valuable metadata such as:

- **Generation prompts**
- **Model settings and parameters**
- **Additional metadata** used during the image creation process

⚡ The extraction happens almost instantly, and **your files stay 100% local** — nothing is uploaded or sent over the internet.

Currently, this tool supports images generated with:

- **ComfyUI**
- **AUTOMATIC1111 Web UI (Stable Diffusion WebUI)**

Whether you’re an artist, developer, or researcher, this tool makes it easy to view and analyze the technical details behind your AI-generated artwork.

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Install dependencies:

   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

2. Start the development server:

   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   # or
   bun dev
   ```

3. Open your browser and visit [http://localhost:3000](http://localhost:3000) to see the app in action.
